# CheckPoint 2 - Application Development

Projeto desenvolvido em HTML, CSS e JavaScript para exibir uma lista de atores e atrizes.

Os dados utilizados estão no arquivo `dados.js`, fornecido na atividade.

## Funcionalidades

- Exibição dos atores e atrizes em cards
- Foto, nome, país e data de nascimento
- Campo de busca por nome
- Filtro conforme o usuário digita
- Layout em grid
- Página responsiva

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Arquivos do projeto

- `index.html`
- `style.css`
- `script.js`
- `dados.js`
- `prints/`
